# Кинопоиск Поиск

Android-приложение: поиск фильмов по названию и открытие страницы на Кинопоиске.

## Скачать

Готовый APK — в разделе [Releases](../../releases/latest).

## Установка

1. Скачайте APK из последнего релиза.
2. Разрешите установку из этого источника.
3. При первом запуске вставьте бесплатный API-ключ с https://kinopoiskapiunofficial.tech/ (раздел «Профиль»).

Приложение само проверяет обновления через GitHub Releases.
